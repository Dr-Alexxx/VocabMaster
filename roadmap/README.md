## 维护规则

1. 每个小版本使用一个 `vX.Y.md`，写明基线、范围、实现状态、依赖和验收条件。
2. 功能实现后更新状态，并链接对应 changelog；延期项保留原因，不从历史计划中悄悄删除。
3. 自动测试、浏览器预览、原生设备和安装包验证分别记录；“实现完成”不表示“已发布”。
4. changelog 按实际交付的 `vX.Y.Z` 归档，发布日期以正式发行时填写，待发布版本使用“未发布”。
5. README 只维护入口与当前能力摘要，详细设计留在本目录，避免版本说明重复漂移。
