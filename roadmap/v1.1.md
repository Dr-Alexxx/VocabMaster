# VocabMaster v1.1 路线图

状态：代码已实现（提交 bb32b6d）；Android 真机和发行包验收另行记录。

基线：v1.0.2。以下保留原始需求和验收标准，勾选实现不等于完成设备验收。

## 1.1：可信、完整、易上手

### P0：统一统计范围与学习模式口径

**问题**：统计页的日期选择只过滤每日趋势，学习模式表现仍读取全量历史；`mixed`、`test` 等模式缺少完整标签。不同模块的指标时间口径容易被误读。

**实施范围**

- 定义并实现统一的统计范围：7 天、30 天、90 天，以及“累计”。
- 除词库总量/掌握度等明确属于当前状态的指标外，所有学习历史指标都使用所选时间范围。
- 学习模式查询按 `study_history.studied_at` 过滤，并覆盖 `flashcard`、`spelling`、`choice`、`mixed`、`test`。
- 明确混合模式和测试题的统计归属，避免同一会话在模式图表中重复计算：优先按每道题实际 `study_mode` 记录；如现有写入数据只保存具体题型，则 UI 说明按实际题型汇总。
- 顶部指标显示当前时间范围内的新学词数、正确率、学习时长；连续天数单独标注为“当前连续”，不随筛选范围变化。
- 图表在无数据时显示空状态，不以 0% 暗示用户表现为零；补充时间范围和指标口径说明。

**验收标准**

- 在 7/30/90 天和累计范围切换时，趋势、模式表现和范围指标同步更新。
- 使用固定日期的测试数据验证边界日期包含规则、时区和跨日行为。
- 每个已支持学习模式都能显示可读标签；无记录模式不产生误导性的 0% 柱条。
- 统计查询不改变当前词库进度和全局连续天数的定义。

### P0：Android 词库文件与完整备份

**问题**：Android 当前不支持词库导入导出、模板下载和学习数据备份恢复，造成与桌面端的主要能力差异。

**实施范围**

- 使用 Capacitor 文件选择能力接收 CSV、XLSX、XLS、JSON、TXT；沿用现有解析器和字段映射逻辑。
- 导入流程支持预览、词库命名、字段映射、重复/无效行统计和提交前取消。
- 使用 Filesystem 写出词库 JSON/CSV、模板和完整备份；使用 Share API 提供系统分享/保存入口。
- 支持从本地文件选择备份并预览；沿用覆盖、合并、跳过三种恢复策略。
- 大文件导入显示进度或阶段状态；设置合理文件大小/行数限制，失败时保留原数据库状态。
- 文案明确说明备份文件包含词库、个人笔记、收藏和学习记录，并提醒用户自行保管文件。
- 更新 README 的平台支持矩阵，移除“下一期暂不支持”旧说明。

**不包含**：云同步、账号系统、自动上传、后台传输。

**验收标准**

- Android 上可导入既有支持格式的代表性文件，预览与桌面解析结果一致。
- 导入事务失败或用户取消时，不留下半成品词库。
- JSON/CSV 导出可从系统分享面板交付到用户选择的位置/应用。
- 备份覆盖、合并、跳过三种策略均能在真实 Android 设备上完成；恢复前可见数据摘要和策略说明。
- 对损坏文件、未知版本、重复词、缺少必填字段、权限拒绝和空间不足给出可理解错误，不丢失已有数据。

### P1：首次启动引导与空状态

**目标**：让新用户第一次打开即可开始有效学习，同时不强迫用户注册或连接网络。

**实施范围**

- 检测是否完成引导；已有用户升级后不重新弹出。
- 步骤一选择考试/词库，展示词数、适用场景和本机占用信息；默认词库仍可在之后调整。
- 步骤二设置每日新词量和复习上限，并可选填写考试截止日期。
- 步骤三提供可跳过的短测（建议 10 题），只用于推荐起始计划，不擅自改写复习记录。
- 首页零词库、无活动词库、计划已完成分别提供明确下一步动作。
- 可从设置重新打开引导或恢复推荐值；不得覆盖用户已有进度。

**验收标准**

- 全新安装可在不超过 3 个主要步骤内进入第一组学习。
- 关闭/跳过引导不会造成页面阻断；下次启动进入正常首页。
- 已有 1.0.2 数据升级后不触发引导，不修改词库启用状态和设置。

### P1：移动端首页与学习设置可用性

**问题**：窄屏首页计划卡片标题换行过多；学习设置的模式选择横向溢出，用户不易发现末尾选项。Android 从常驻底栏进入“学习”后，尚未开始答题就立刻进入隐藏底栏的全屏学习壳，设置状态和专注答题状态的导航行为不一致。

**实施范围**

- 窄屏首页将待复习、新词和目标进度设为短标签/数值组；控制主标题长度，保证主操作在首屏可见。
- 学习模式选择在窄屏改为可换行网格或视觉明确的横向滚动区；确保“测试”不被截断且不依赖手势才能发现。
- 来源选项同样保证完整可见；选中态、焦点态和禁用态在深浅主题下清楚。
- 将学习入口拆分为普通导航状态与沉浸答题状态：刚从底栏进入、尚未点击“开始本次学习”时保留 Android 底栏；用户开始一组答题后才隐藏底栏并进入全屏专注界面。
- 学习设置状态下切换到底栏其他主页面，再返回时保留本次选择的模式和来源；不要因此开始答题或丢失配置。
- 答题中按返回键/页面返回按钮时优先显示暂停/结束选择；结束后回到今日页或原学习入口，并恢复常驻底栏。避免系统返回直接丢弃进行中的题目或造成意外提交。
- 学习完成页属于沉浸流程的收尾状态，可保留无底栏布局；返回首页后恢复全局导航。
- 设置页底部导航安全区和滚动留白保持足够；窄屏控件不溢出视口。

**验收标准**

- 在 320、360、390、430 CSS px 宽度检查首页、学习设置、答题页和设置页，无横向页面滚动、文字重叠或按钮被底栏遮挡。
- Android 从“今日”底栏点“学习”时，学习设置页仍可见四项底栏；点击开始后底栏隐藏，答题区域使用全屏空间。
- 在学习设置页切换到底栏其他 Tab 并返回，模式、来源和筛选配置仍保留；不会意外开启学习。
- Android 系统返回、页面返回、暂停后继续和结束本次学习的导航结果一致且不会静默丢失当前进度。
- 键盘、触屏和辅助技术均能到达全部模式及来源选项。
- 使用浅色/深色主题、较大字体和系统安全区各做一次检查。

### P1：Android 实际答题界面专项调整

**问题**：Android 学习页目前沿用响应式桌面布局的主要结构，学习设置、答题卡片、反馈和底部操作在窄屏及软键盘弹出时容易显得拥挤或位置失衡。此项与首页/设置页的响应式修整分开验收，聚焦真正答题的连续操作体验。

**实施范围**

- 为手机答题页建立稳定的纵向布局：顶部返回/暂停/进度、题目主体、答案操作区各自有明确位置；内容变化时不引起按钮跳动或被遮挡。
- 重新检查选择题的题干与选项密度、长释义换行、正确/错误反馈和“下一题”按钮；选项应有足够触控面积，避免反馈信息挤压题目。
- 调整卡片翻面与 0–5 自评布局，保证小屏幕上评级按钮可见且可轻松点击；不要求用户为了评分滚动整页。
- 调整拼写模式在软键盘弹出、输入焦点变化和答案反馈阶段的布局；输入框、提交/下一题按钮应始终可达，页面需正确响应 Android 可视视口和系统导航区变化。
- 评估是否为 Android 使用更明确的全屏专注模式，弱化桌面式工具装饰；返回、暂停、发音、收藏和详情仍应容易找到。
- 让学习模式/来源选择控件在窄屏下明确显示当前选项及完整选项集合；优先使用分行网格或紧凑单选列表，避免看起来像未完成的横向轮播。
- 分别检查系统三键导航与手势导航、安全区、横竖屏切换、较大系统字号和深浅主题。

**验收标准**

- 在至少一台小屏 Android 手机和一台常见尺寸手机上走完选择题、卡片和拼写流程；仅用模拟器尺寸作为补充，不替代真机检查。
- 在 320–430 CSS px 宽度和短屏高度下，题干、全部必要操作及反馈不重叠、不被系统栏/软键盘遮挡，页面没有意外横向滚动。
- 软键盘打开时拼写输入及提交操作可见；提交后收起键盘不会把“下一题”推到屏幕外。
- 选择题四个选项和卡片评级按钮均可单手触达，触控目标至少 44×44 CSS px。
- 暂停、恢复、详情抽屉、朗读、收藏、稍后再学与快捷键状态在触屏流程中行为一致；不支持的键盘提示不误导手机用户。
- 对桌面布局进行回归，确保 Android 专项调整没有压缩桌面学习卡片或改变现有 SM-2 交互。

### P1：学习完成反馈和错题回流

**实施范围**

- 完成页区分新词、到期复习、错题专项和测试题数。
- 展示本次正确率、耗时及错题/薄弱词数量。
- 提供“复习本次错题”和“返回今日计划”两个清晰动作。
- 普通学习展示少量错题预览；测试可打开完整成绩报告和错题列表。
- 统计“下一次复习日期”仅在调度结果可解释且数据已持久化后展示。

**验收标准**

- 完成页上的题数与实际成功写入的学习记录一致；提交失败的题不计入完成数。
- 错题回流只包含本次答错词，不意外重置其他单词的复习计划。
- 空计划仍有返回首页和调整词库入口。

### P2：性能、保存状态和交互收尾

- 将 ECharts 图表代码拆分为按需加载 chunk；核对桌面和 Android 首屏加载时间及包体积。
- 设置自动保存增加“保存中 / 已保存 / 保存失败，重试”状态，避免只展示静态成功提示。
- 单词抽屉收藏更新失败时回滚乐观状态并显示错误。
- 快捷键在学习页暂停层或设置中提供可访问的完整清单；移动端不展示无效提示。

**验收标准**

- 首屏不再加载统计图表模块；进入统计页后才加载图表 chunk。
- 保存失败可明确观察并重试；重启应用后值与界面一致。
- 收藏失败后按钮与数据库状态一致。
