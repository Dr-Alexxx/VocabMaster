# VocabMaster v1.1.0

v1.1.0 在 v1.0.2 的基础上完善了手机学习体验、数据管理和个性化复习。词库、学习记录与笔记继续保存在本机，核心学习无需账号或网络。

## 更顺畅的学习体验

- Android 从底栏进入学习设置时保留导航，开始答题后进入专注全屏；返回、暂停和结束学习的流程更清晰。
- 优化手机首页、学习模式选择、词列表和答题反馈，减少窄屏截断与操作拥挤。
- 新增首次设置引导与可跳过的短测；完成页显示新词、复习和错题明细，可直接复习本次错题。

## 按自己的节奏复习

- 新增自适应每日计划，根据近期完成情况和复习积压推荐新词量，可手动调整，始终不超过每日上限。
- 新增可选 FSRS-6，支持目标记忆保持率和切换前排期预览。默认仍使用 SM-2，已有学习历史会保留。
- 新增本地到期提醒，可设置提醒时间、工作日和免打扰时段，默认关闭。

## 更好地管理词汇与数据

- 收藏支持自定义标签、筛选和标签专项复习。
- 错题可标注拼写、释义混淆、听音、粗心等原因，并按原因筛选练习。
- 统一 7/30/90 天和累计统计，补齐混合模式、测试和错题原因统计。
- Android 新增词库导入、导出、模板分享和完整备份恢复。
- 单词详情支持词根、词族、搭配、素材来源/许可和例句朗读。

## macOS 下载与安装

本次提供 **Apple Silicon / arm64** 构建，适用于 macOS 13 或更高版本：

| 文件 | 用途 |
| --- | --- |
| `VocabMaster-Setup-1.1.0-mac-arm64.dmg` | 打开后将 VocabMaster 拖入“应用程序” |
| `VocabMaster-1.1.0-mac-arm64.zip` | 解压得到 VocabMaster.app |

当前 macOS 包未配置 Apple 开发者签名与公证。首次打开如被系统阻止，请参考仓库 README 的 macOS 安装说明。

## 升级与注意事项

- 升级前建议在“设置 → 数据管理”导出完整备份。本版本支持旧数据库迁移和格式 1.0 的备份。
- 新导出的备份格式编号为 **1.2**，与应用版本 **1.1.0** 相互独立；新备份需使用本版本或之后的兼容版本恢复。
- 桌面提醒需要应用保持运行。Android 预排未来 14 天并在打开应用或学习后更新，系统省电可能延后提醒。
- FSRS 使用默认权重；离线朗读取决于本机已安装的系统语音。
- macOS 包完整性和打包运行时检查已通过；原生通知投递、Android 真机及安装升级仍待设备验收。

详细变更见 `changelog/CHANGELOG-v1.1.0.md`。
