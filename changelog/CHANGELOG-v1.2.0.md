# VocabMaster v1.2.0

状态：未发布，待原生设备与安装包验收。基线：v1.1.0。

## 新增

- 本地到期提醒：启用开关、每日/工作日、提醒时间、免打扰时段、权限状态和系统设置入口。
- 自适应学习计划：依据近期完成率、复习积压和答题耗时推荐新词数，支持本次目标预览/手动调整，始终受每日上限约束。
- FSRS-6 可选算法（ts-fsrs 5.4.2），目标保持率、切换前排期模拟、学习历史参数快照及切回 SM-2；默认继续使用 SM-2。
- 收藏与标签管理：多标签关联、创建/重命名/删除、筛选和标签专项复习。
- 错题原因：拼写错误、释义混淆、听音不识、粗心、其他；支持答题后标注及详情补改。
- 错因分布和每日变化统计；错题本按最近错误原因筛选。
- 词根/词缀、词族、搭配、来源和许可扩展字段；导入模板及 CSV/JSON 导出保持可选字段。
- 单词详情中的例句朗读。
- 供开发验收使用的本机内存 SQLite 预览，不接触真实学习数据库。

## 修复与兼容性

- 每日计划扣除已完成的新词/复习量，截止目标不再突破每日上限。
- 记录缺席日，避免自适应计划只取成功学习的样本。
- 完整备份升至 1.2，兼容读取旧 1.0；保存 FSRS、标签、原因、每日计划和扩展素材字段。
- SQLite 版本升至 3，桌面/Android 共用幂等迁移；备份关联按实际单词/记录 ID 重建，完整性异常时回滚。
- Android 数据操作串行执行，迁移和恢复不再嵌套启动 SQLite 隐式事务。
- 修复缓存学习页再次点击首页学习入口/标签专项不能正确重新开始的问题。
- 退出答题先暂停，结束后恢复首页导航；手机词列表不再截断主要信息，禁用选项保持反馈可读性。

## 验证与限制

- 自动回归 16 个测试文件、199 项断言通过；最终算法时间修正后再次通过 4 个相关套件（32 项断言）。Web 构建与 Capacitor 同步通过，Android 识别 5 个插件（含 local-notifications）。
- 390px 本机浏览器预览验证 FSRS 切换、学习底栏状态、错因保存、标签关联/筛选及退出保护，无浏览器错误。
- 原生通知投递、Android 真机、APK/桌面安装包验收尚未完成。
- 桌面应用完全退出后不发送通知；Android 预排未来 14 天并在打开/前台/学习后更新，系统省电可能延后普通提醒。
- FSRS 使用默认权重，未提供个人权重训练；没有可核验再分发许可的第三方离线音频包，本版继续使用本机系统语音。
- 1.2 格式备份需使用 v1.2 或更高版本恢复；旧版本应用不能读取新的标签与算法状态。
