# VocabMaster v1.1.0

状态：待发布。基线：v1.0.2。当前已生成 macOS arm64 DMG/ZIP；正式发行日期以发布时填写。

## 新增

- 首次启动引导：选择词库、设置每日学习量和可跳过的 10 题评估，不自动修改已有学习记录。
- Android 通过系统文件选择器导入 CSV、XLSX、XLS、JSON、TXT，支持词库/模板分享与完整备份导出、覆盖/合并/跳过恢复。
- 本地到期提醒：时间、每日/工作日、免打扰、权限状态及系统设置入口，默认关闭。
- 自适应每日计划：参考完成率、复习积压及耗时推荐新词量，提供预览/手动调整，并受每日上限约束。
- FSRS-6 可选算法：目标保持率、切换前排期模拟、算法参数历史与切回 SM-2；SM-2 仍为默认。
- 收藏与标签：多标签关联、创建/重命名/删除、筛选和标签专项复习。
- 错题原因标注、详情补改、按原因专项练习，以及原因数量和每日变化统计。
- 可选词根/词缀、词族、搭配、来源和许可字段；例句支持系统语音朗读。
- 完成页新词/复习/错题明细、错题预览与“复习本次错题”。

## UI、统计与交互

- Android 学习设置保留底栏，正式答题进入全屏；暂停/结束和返回首页恢复导航。
- 优化手机首页卡片、模式选择、词列表、评级/反馈及输入布局；增加 Android 返回键处理和答题退出保护。
- 修复缓存学习页无法从首页或标签专项正确重新开始的问题。
- 7/30/90 天与累计统计统一学习量、正确率、时长和模式表现的时间口径；补齐混合/测试模式。
- 无学习记录使用明确空状态；近 18 周热力图保持独立范围。
- ECharts 按需加载；设置显示保存中/已保存/失败，收藏写入失败回滚界面。

## 数据与兼容性

- 每日计划扣除已完成量；缺席日纳入自适应样本，截止目标不突破上限。
- 数据库版本为 3，共用幂等迁移；新增会话模式、算法历史、标签、错因、每日计划及素材字段。
- 完整备份格式编号为 1.2，独立于应用版本 v1.1.0；继续读取格式 1.0。保留 FSRS 状态、标签和原因，关联异常时事务回滚。
- Android 数据操作串行执行，避免迁移/恢复嵌套启动 SQLite 隐式事务。
- 导入跳过重复/无效行，空词库事务回滚；CSV/JSON 导出保留可选扩展字段。

## 已知限制

- macOS 发行包未配置 Apple 开发者签名与公证。
- 桌面应用完全退出后不提醒；Android 预排 14 天并在前台/学习后更新，系统省电可能延后投递。
- FSRS 使用默认权重，不提供个人权重训练；切回 SM-2 后从保留的 SM-2 状态继续，不反向重放 FSRS 评分。
- 未添加第三方离线录音包；系统朗读的离线可用性取决于本机已安装的语音。
- 格式 1.2 的新备份需使用本次 v1.1.0 或之后的兼容版本恢复；v1.0.2 不能读取新标签和算法状态。
