# VocabMaster v1.1.0

发布日期：待发布

## 新增

- Android 支持通过系统文件选择器导入 CSV、XLSX、XLS、JSON 和 TXT 词库。
- Android 支持分享词库、CSV/Excel/JSON 模板和完整学习数据备份。
- Android 支持从本地备份恢复数据，并提供覆盖、合并、跳过三种策略。
- 新增首次启动引导：选择词库、设置每日学习计划和可跳过的 10 题快速评估。
- 学习完成页显示新词数、复习数、错题数，并可直接复习本次错题。
- 设置页增加自动保存状态反馈。

## 学习与导航

- Android 从底栏进入学习设置时保留底栏导航。
- 点击开始学习后进入沉浸式答题界面，完成页保留沉浸布局，结束学习/返回首页后恢复常规导航。
- 增加 Android 系统返回键、暂停、继续和结束学习的处理。
- 优化窄屏首页计划卡片、学习模式选择、来源选择和答题布局。
- 优化拼写模式软键盘、卡片评级和选择题触控区域。

## 统计

- 统计页支持 7 天、30 天、90 天和累计范围。
- 学习量、正确率、学习时长和学习模式表现统一按所选范围统计。
- 补齐卡片、拼写、选择题、混合和测试模式标签。
- 无学习数据时显示明确空状态，避免用 0% 造成误解。
- ECharts 改为进入统计页后按需加载。

## 数据与兼容性

- 学习历史新增会话模式字段，用于区分混合模式和词汇测试。
- 兼容 1.0.2 数据库和旧版本备份文件。
- 导入词库时支持字段映射、重复行跳过、无效行统计和事务回滚。
- 单词收藏保存失败时自动回滚界面状态。
- 版本号更新为 `1.1.0`。

## 验证

- `npm test`：15 个测试文件，185 项断言通过。
- `npm run build:web`：通过。
- `npm run cap:sync`：通过，Android 识别 SQLite、App、Filesystem、Share 插件。
